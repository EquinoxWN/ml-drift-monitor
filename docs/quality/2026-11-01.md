# Quality check, 2026-11-01

The ten engineering rules, checked against the code on `main`, with the evidence. Run on Windows 11
with Python 3.14 in the repository's `.venv`.

| # | Rule | Status | Evidence |
|---|---|---|---|
| 1 | Assume every call can fail | pass | No network, database or subprocess calls: the tool reads local CSV and JSON files. Every file error is reported: the CLI turns `ValueError`, `OSError`, `KeyError` and `LockedError` into exit code 2 with a message (`cli.py`). No bare `except`, no `except ... pass`. A crashed run releases its lock (`finally`, `test_a_crash_keeps_the_work_already_done`). |
| 2 | Writes safe to retry | pass | Reports, `state.json` and the reference are written to a `.tmp` file and renamed with `os.replace` (`jobs._write_atomic`, `reference.save`). State is saved after each batch, so a rerun after a crash checks only the unfinished batch (mutant D10 is killed). A batch is re-checked only when its SHA-256 changes. `check --json` overwrites one output file with the same content on a rerun. |
| 3 | No race conditions | pass | A run takes `out/.lock` with `O_CREAT` and `O_EXCL`, so a second run is refused (`test_concurrent_runs_are_refused`). The process is single-threaded. |
| 4 | Don't trust the clock | pass | No timestamps are stored. `scripts/measure.py` times with `time.perf_counter`. Batches are ordered by file name, not time. |
| 5 | Read before changing | pass | No environment variables are read. Every path in the README exists. |
| 6 | Never break compatibility | pass | The reference format carries `version: 1`; other versions are refused. Report and state formats are unchanged. |
| 7 | One source of truth | pass | The reference names its source file and SHA-256 and is rebuilt only by `drift reference`; `state.json` maps each batch name to the SHA-256 it was checked at, so a changed file is re-checked. numpy, SciPy and tool versions agree between README and `pyproject.toml`. |
| 8 | Small changes, no secrets, validate input | fixed | `git grep -iE "(api[_-]?key|secret|token|password)\s*[:=]"`: no matches. CSV size, row count, numbers, columns and the reference checksum were validated, but three shapes crashed with a traceback instead of exit 2: a schema file that is not an object (`TypeError`), a schema entry that is not an object (`AttributeError`), and a `state.json` that is not a map (`AttributeError`). Each is now a `ValueError` with a clear message (`cli.py`, `data.parse_schema`, `jobs.run_pending`), with a test each. No new dependency. |
| 9 | Tests that can actually fail | fixed | No `skip`, `xfail` or tautologies; warnings are errors. Mutation check below: 5 of 17 survived; each now has a test that kills it. |
| 10 | Re-verify | pass | `ruff check .`: `All checks passed!`; `ruff format --check .`: clean; `mypy`: `Success: no issues found in 17 source files`; `pytest -q`: `70 passed`; `pip-audit`: `No known vulnerabilities found` (after `pip install --upgrade pip`, as `make setup` does; the venv's bundled pip 26.1.1 had PYSEC-2026-196 and PYSEC-2026-3721); demo: `RESULT run: 7 checked, 0 already done, 4 with drift`; `audit_repo.py`: OK. CI on push. |
